Vizsgatevékenység: Backend és frontend webfejlesztés
A vizsgafeladat időtartama: 90 perc (45 + 45 perc)  |  Elérhető pontszám: 40 pont

1. Backend feladat – REST API fejlesztés PHP + MySQL

Egy mozis adatbázis-kezelő rendszer backendjét kell elkészítenie. Az adatbázis két táblát tartalmaz: rendezok és filmek, amelyek idegen kulccsal vannak összekapcsolva. Az API-t a localhost szerveren, a /api/filmek/ útvonalon kell elérhetővé tenni.

Az adatbázis neve: moziadatbazis

Adatbázis séma:
rendezok
id         INT, PK, AUTO_INCREMENT
nev        VARCHAR(100)
szuletesi_ev INT
nemzetiseg   VARCHAR(50)
filmek
id         INT, PK, AUTO_INCREMENT
cim        VARCHAR(150)
rendezo_id   INT, FK → rendezok.id
ev         INT
mufaj      VARCHAR(50)
ertekeles   DECIMAL(3,1)
jatekido    INT (percben)
A mellékelt moziadatbazis.sql fájlban a teljes adatbázis megtalálható (20 rendező, 55 film). Importálja be phpMyAdmin segítségével!

Feladatok

  1. Importálja be a moziadatbazis.sql fájlt phpMyAdmin segítségével! Ellenőrizze, hogy mindkét tábla és az idegen kulcs kapcsolat helyesen létrejött! (1 pont)
  2. Hozzon létre egy kapcsolat.php fájlt, amely tartalmazza az adatbázis-kapcsolat adatait és felépíti a kapcsolatot! (1 pont)
  3. Készítse el az API belépési pontját (index.php) a /api/filmek/ útvonalon! A kérés típusát switch-case szerkezettel kezelje, és minden ágban hívjon meg egy-egy megfelelő függvényt! Állítsa be a válasz fejlécét JSON típusúra és engedélyezze a CORS-t! (2 pont)
  4. Valósítsa meg a GET kérést!
    • Paraméter nélkül adja vissza az összes filmet a rendező nevével együtt (JOIN segítségével) JSON tömbként!
    • ?id= paraméter esetén adja vissza csak az adott film adatait a rendező nevével, születési évével és nemzetiségével együtt!
    • ?mufaj= paraméter esetén adja vissza az adott műfajhoz tartozó összes filmet!
    (4 pont)
  5. Valósítsa meg a POST kérést! A kérés törzsében JSON formátumban érkeznek az új film adatai (cim, rendezo_id, ev, mufaj, ertekeles, jatekido). Szúrja be az új filmet, és adja vissza: {"uzenet": "Film sikeresen hozzaadva", "id": <új id>} (3 pont)
  6. Valósítsa meg a PUT kérést! A ?id= paraméterrel azonosított film ertekeles mezőjét frissítse a kérés törzsében érkező új értékre! Visszatérési érték: {"uzenet": "Ertekeles frissitve"} (3 pont)
  7. Valósítsa meg a DELETE kérést! A ?id= paraméterrel azonosított filmet törölje! Ha az id nem létezik: {"hiba": "Nem talalhato"} (3 pont)
  8. A switch-case default ágában adjon vissza hibaüzenetet: {"hiba": "Ismeretlen metodus"} (1 pont)
Minta – GET /api/filmek/ válasza (részlet):
[ { "id": "1", "cim": "Inception", "rendezo": "Christopher Nolan", "ev": "2010", "mufaj": "sci-fi", "ertekeles": "8.8", "jatekido": "148" }, ... ]
Minta – GET /api/filmek/?id=1 válasza:
{ "id": "1", "cim": "Inception", "rendezo": "Christopher Nolan", "szuletesi_ev": "1970", "nemzetiseg": "brit", "ev": "2010", "mufaj": "sci-fi", "ertekeles": "8.8", "jatekido": "148" }

2. Frontend feladat – HTML + CSS + JavaScript (fetch)

Készítsen egy reszponzív webes felületet, amely az előző feladatban elkészített REST API-t használja! Az oldal neve legyen index.html, a stílusok kerüljenek egy külön stilus.css fájlba, a JavaScript kód pedig egy külön app.js fájlba!

Ha az előző feladatban az API-t nem sikerült elkészíteni, a következő nyilvános tesztAPI-t is használhatja: https://freetestapi.com/api/v1/movies

Feladatok

  1. Hozza létre az oldal alapszerkezetét (index.html)! Az oldalon legyen egy fejléc a mozi neve és egy rövid leírás szöveggel, egy főterület a filmek listájának és az űrlapnak, valamint egy lábléc! (1 pont)
  2. Az oldal betöltésekor automatikusan hívja meg az API GET végpontját és jelenítse meg az összes filmet kártyás elrendezésben! Minden kártyán szerepeljen a film címe, rendezője, éve, műfaja, játékideje és értékelése! (3 pont)
  3. Valósítson meg műfaj szerinti szűrést! Egy <select> legördülő listában jelenjenek meg a műfajok (ezeket az API válaszából gyűjtse ki JavaScriptben, ne kézzel írja be)! A kiválasztott műfajra kattintva a lista automatikusan frissüljön, az API ?mufaj= paraméterével! (3 pont)
  4. Készítsen űrlapot új film hozzáadásához! Az űrlapon legyen beviteli mező a cim, rendezo_id, ev, mufaj, ertekeles és jatekido mezőkhöz, valamint egy „Hozzáadás" gomb! A gomb hatására POST kéréssel küldje el az adatokat, majd frissítse a filmlistát! (3 pont)
  5. Minden filmkártyán helyezzen el egy „Törlés" gombot! Kattintásra confirm() megerősítés után DELETE kéréssel törölje a filmet, majd frissítse a listát! (2 pont)
  6. Minden filmkártyán legyen egy „Értékelés módosítása" gomb! Kattintásra prompt() ablakban kérje be az új értékelést, majd PUT kéréssel küldje el és frissítse a listát! (2 pont)
  7. Alakítsa ki az oldal stílusát (stilus.css)!
    • Széles képernyőn (min-width: 768px) a kártyák egymás mellett, keskeny képernyőn egymás alatt jelenjenek meg (Flexbox vagy Grid)!
    • A kártyákon legyen árnyék, lekerekített sarok és megfelelő belső margó!
    • A gombok különböző színűek legyenek: törlés – piros, módosítás – kék, hozzáadás – zöld!
    (3 pont)
  8. API hiba esetén (pl. sikertelen törlés) jelenítsen meg hibaüzenetet az oldalon egy piros hátterű div-ben (ne alert()-tel)! (1 pont)
  9. Valósítson meg cím szerinti keresést egy szövegmezővel! A szűrés az API újrahívása nélkül, kizárólag JavaScriptben, a már betöltött adatokon történjen! (2 pont)
